# Codex setup backup

Portable Codex setup for the Sviriel team and personal machines.

Start with [`INSTALL.md`](INSTALL.md). It covers Windows, macOS, and Linux,
choosing the local LLM Wiki path, Flutter/Dart MCP, Python, and Z.A.E.B.A.L.

The package includes:

- `INSTALL.md` — portable installation guide;
- `codex/AGENTS.md.template` — global instruction template;
- `codex/config.toml.example` — Flutter/Dart MCP example;
- `skills/` — selected skills for Codex.

Machine-specific `config.toml`, `hooks.json`, authentication files, logs, chat history,
memories, internal Codex databases, session files, and private Wiki content are not part
of this portable export.

Wiki остаётся внешним источником по пути `H:\LLM-WIKI` и в этот backup не копируется.
